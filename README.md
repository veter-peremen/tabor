# Бот-афиша мероприятий (Telegram, aiogram 3)

Телеграм-бот для ведения расписания мероприятий и оповещения пользователей.
Хранилище — локальная база **SQLite**, режим работы — **long polling**.

## Возможности

**Пользователю:**
- просмотр всех предстоящих мероприятий;
- расписание одним сообщением: строки вида «#ID дата время • Название», где **#ID — кликабельная ссылка** (deep-link). Фильтры **комбинируются**: дата (сегодня / на этой неделе / в этом месяце / все) + **несколько жанров** + локация;
- по клику на название открывается карточка мероприятия с кнопками: ❤️ в избранное (всем), а админам — ✏️ изменить и 🗑 удалить (после правки/удаления сообщение-расписание само обновляется);
- в карточке мероприятия **название площадки — тоже ссылка**: открывает карточку площадки (адрес, соцсеть, возрастное ограничение); админу там доступно ✏️ редактирование данных площадки. Возрастное ограничение площадки в карточке мероприятия не показывается (у мероприятия оно может отличаться);
- добавление мероприятий в избранное;
- настройка напоминаний по избранному (за неделю / за день / в день события) — можно включить несколько;
- предложить своё мероприятие (уходит админам на модерацию). У администратора эта кнопка заменена на **«Добавить мероприятие»** — его события попадают в расписание сразу, без модерации.

Мероприятию можно назначить **несколько жанров** (мультивыбор в форме).

**Админу:**
- добавление жанров и локаций;
- добавление мероприятий в расписание;
- уведомления о предложенных пользователями мероприятиях, их правка и добавление/отклонение;
- редактирование и удаление мероприятий;
- **управление пользователями** (👥 Пользователи): назначение и снятие роли администратора, бан и разбан пользователей;
- рассылка любого поста всем пользователям командой `/broadcast`.

**Роли и бан:**
- суперадмины (из `SUPERADMIN_IDS`) неприкосновенны — их роль нельзя снять или забанить из бота;
- нельзя менять собственную роль/статус;
- забанить можно только пользователя без роли администратора (сначала снимите роль);
- забаненный пользователь полностью игнорируется ботом до разбана.

Роль **суперадмина** задаётся через переменную окружения `SUPERADMIN_IDS` — эти
пользователи получают права администратора автоматически при первом заходе.

## Структура

```
bot.py                     # точка входа (long polling)
app/
  config.py                # чтение .env
  middlewares.py           # инъекция сессии БД и записи пользователя
  states.py                # FSM-состояния
  keyboards.py             # клавиатуры
  utils.py                 # парсинг дат/времени, форматирование карточки события
  db/
    models.py              # SQLAlchemy-модели
    session.py             # движок и фабрика сессий
    crud.py                # операции с БД
  handlers/
    common.py              # /start, /help, /cancel, /myid
    eventform.py           # общий сценарий заполнения мероприятия (админ + предложение)
    user.py                # просмотр, фильтры, избранное, напоминания
    admin.py               # админ-панель, модерация, /broadcast
  services/
    reminders.py           # фоновый планировщик напоминаний
```

## Установка и запуск (Windows / PowerShell)

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
   Свой Telegram ID можно узнать у [@userinfobot](https://t.me/userinfobot)
   или отправив боту команду `/myid` после запуска.

2. Настройте окружение:
   ```powershell
   copy .env.example .env
   # откройте .env и впишите BOT_TOKEN и SUPERADMIN_IDS
   ```

3. Установите зависимости и запустите:
   ```powershell
   py -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe bot.py
   ```

При первом запуске автоматически создаётся файл базы (`events.db` по умолчанию).

### Если Telegram заблокирован (нужен прокси/VPN)

Если при запуске бот пишет «Не удаётся подключиться к Telegram», значит прямой
доступ к `api.telegram.org` закрыт. Варианты:

- **Полноценный системный VPN** (не браузерный) — включить и запустить бота как обычно.
- **Локальный прокси-клиент** (Hiddify / Outline / V2Ray и т.п.): такие приложения
  поднимают прокси на `127.0.0.1:PORT`. Пропишите его в `.env`:
  ```
  PROXY=http://127.0.0.1:12334
  ```
  и убедитесь, что клиент запущен и подключён, пока работает бот.
  Для прокси aiogram требует пакет `aiohttp-socks` (уже в `requirements.txt`).

> Порт прокси можно посмотреть в настройках клиента (в Hiddify — системный прокси
> вида `http://127.0.0.1:12334`).

## Как пользоваться

- Нажмите **🛠 Админ-панель** → заведите пару жанров и локаций, затем добавляйте мероприятия.
- Обычный пользователь видит меню без админ-панели: смотрит афишу, отмечает избранное, настраивает напоминания.
- **Рассылка:** в личке с ботом ответьте командой `/broadcast` на любое сообщение
  (текст, фото, пост с кнопками) — оно будет скопировано всем пользователям бота.

## Как работают напоминания

Каждую минуту планировщик проверяет мероприятия из избранного пользователей.
Для каждого включённого типа напоминания (за неделю / за день / в день события)
уведомление отправляется один раз (повторы исключаются таблицей `sent_reminders`).

Напоминание типа считается «наступившим», как только текущий момент прошёл
точку срабатывания (`начало − 7 дней` / `начало − 1 день` / наступил день события)
и событие ещё не началось. Такой подход устойчив к простою бота: если он был
выключен в нужную минуту, напоминание отправится при следующем запуске. Побочный
эффект: если добавить в избранное мероприятие, до которого меньше недели, при
включённом «за неделю» — соответствующее уведомление придёт почти сразу
(с корректным текстом «до начала: N дн.»).
